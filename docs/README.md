# Документация проекта «ФинУчёт»

Комплект программной документации разработан в соответствии с требованиями
**Единой системы программной документации (ЕСПД)**; состав комплекта определён
разделом 5 технического задания. Оформление документов — по **ГОСТ 19.106-78**
(лист А4, Times New Roman 14 пт, межстрочный интервал 1,5, абзацный отступ 1,25 см,
поля 30/15/20/20 мм, сквозная нумерация страниц).

## Работа с документами

**DOCX.** При первом открытии руководства пользователя в Microsoft Word или LibreOffice
Writer подтвердите обновление полей документа — содержание будет заполнено автоматически
с номерами страниц.

**Диаграммы.** Файлы диаграмм отображаются прямо на GitHub. Локально — Visual Studio Code
с расширением *Markdown Preview Mermaid Support* либо сайт [mermaid.live](https://mermaid.live).

**Снимки экранов.** Каталог `user-guide/images` содержит 21 файл PNG; они используются
и в DOCX-версии руководства, и в Markdown-версии.
