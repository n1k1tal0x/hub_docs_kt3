Диаграммы выполнены в текстовом формате [Mermaid](https://mermaid.js.org/) и отображаются
непосредственно на GitHub — достаточно открыть нужный файл. Исходный текст диаграммы

с кодом и отслеживать изменения.

## Если диаграмма не отображается

Отображение Mermaid поддерживается GitHub, GitLab и многими редакторами Markdown.
Локально диаграммы удобно просматривать:

- в Visual Studio Code — расширение **Markdown Preview Mermaid Support**;
- в браузере — на сайте [mermaid.live](https://mermaid.live) (вставить текст из блока ```` ```mermaid ````);
- экспорт в PNG/SVG — утилитой `@mermaid-js/mermaid-cli`:

```bash
npx -p @mermaid-js/mermaid-cli mmdc -i 02-er-diagram.md -o er-diagram.png
```
