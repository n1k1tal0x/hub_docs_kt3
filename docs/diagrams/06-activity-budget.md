# Схема алгоритма: контроль исполнения бюджета

Документ: ФИНУЧЁТ.001-01 · Стадия: технический проект
Реализуемое требование: ФТ-5 (планирование и контроль бюджетов)

Алгоритм выполняется после успешного сохранения операции расхода.

```mermaid
flowchart TD
    A(["Начало: операция расхода сохранена"]) --> B["Определить категорию операции C<br/>и месяц операции (год Y, месяц M)"]
    B --> C{"Категория C —<br/>подкатегория?"}
    C -- "да" --> D["C := родительская категория"]
    C -- "нет" --> E
    D --> E["Найти лимит L для (C, Y, M)"]
    E --> F{"Лимит задан?"}
    F -- "нет" --> Z(["Конец: сообщения не выводятся"])
    F -- "да" --> G["Вычислить фактический расход S<br/>по категории C и её подкатегориям за месяц"]
    G --> H["Вычислить процент исполнения<br/>P := S / L × 100"]
    H --> I{"P > 100 %?"}
    I -- "да" --> J["Индикатор категории — красный"]
    J --> K["Вывести предупреждение:<br/>«Превышен лимит бюджета по категории …»"]
    K --> L["Записать в журнал:<br/>WRN Лимит «…»: P %"]
    L --> Y
    I -- "нет" --> M{"P ≥ 80 %?"}
    M -- "да" --> N["Индикатор категории — жёлтый"]
    N --> O["Вывести предупреждение:<br/>«Достигнуто 80 % лимита по категории …»"]
    O --> Y
    M -- "нет" --> Q["Индикатор категории — зелёный"]
    Q --> Y["Обновить карточку категории<br/>и итоги раздела «Бюджеты»"]
    Y --> Z
```

## Соответствие требованию ФТ-5

| Условие | Цвет индикатора | Сообщение | Состояние `BudgetState` |
|---|---|---|---|
| `P < 80 %` | зелёный | не выводится | `Normal` |
| `80 % ≤ P ≤ 100 %` | жёлтый | «Достигнуто 80 % лимита по категории …» | `Warning` |
| `P > 100 %` | красный | «Превышен лимит бюджета по категории …» | `Exceeded` |

Предупреждения носят информационный характер: операция остаётся сохранённой,
решение о корректировке расходов или лимита принимает пользователь.
Расход по категории первого уровня включает расходы всех её подкатегорий.
