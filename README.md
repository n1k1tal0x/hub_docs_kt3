# ФинУчёт — учёт личных финансов

**Настольное приложение для Windows, которое заменяет ведение личного бюджета в таблицах:**
регистрирует доходы, расходы и переводы между счетами, автоматически пересчитывает остатки,
контролирует месячные лимиты по категориям и строит аналитические отчёты с диаграммами.
Все данные хранятся локально, в файле SQLite на компьютере пользователя — без облака,
без абонентской платы и без подключения к сети Интернет.

## Возможности

| Возможность | Описание | Требование ТЗ |
|---|---|:--:|
| **Счета** | Наличные, банковские карты, счета и вклады. Начальный остаток, валюта по ИСО 4217, архивирование. Текущий остаток пересчитывается автоматически | ФТ-1 |
| **Операции** | Доходы, расходы и переводы между счетами. Контроль суммы, даты и совпадения счетов; перевод пишется в одной транзакции | ФТ-2 |
| **Категории** | Двухуровневый справочник доходов и расходов с цветами для диаграмм; 24 предустановленные категории при первом запуске | ФТ-3 |
| **Поиск и фильтрация** | Отбор по периоду, счёту, типу, категории и подстроке комментария; постраничный вывод и итоги по отбору. До 2 с на базе в 50 000 операций | ФТ-4 |
| **Бюджеты** | Месячные лимиты по категориям, индикаторы исполнения: зелёный — менее 80 %, жёлтый — 80…100 %, красный — более 100 % с предупреждением | ФТ-5 |
| **Отчёты** | «Доходы и расходы за период», «Структура расходов» (круговая диаграмма), «Динамика по месяцам» (столбчатая диаграмма). До 3 с на базе в 50 000 операций | ФТ-6 |
| **Обмен данными** | Экспорт и импорт CSV (UTF-8, разделитель `;`, RFC 4180) с построчным контролем и протоколом импорта | ФТ-7 |
| **Резервные копии** | Автоматическая копия при каждом запуске, хранение 5 последних, восстановление с подтверждением | ФТ-8 |
| **Защита данных** | Вход по паролю; хеш PBKDF2-HMAC-SHA256, 100 000 итераций, соль 16 байт; блокировка на 60 с после 3 неверных попыток | ФТ-9 |
| **Настройки** | Валюта по умолчанию, формат даты, светлая и тёмная темы; параметры сохраняются между сеансами | ФТ-10 |

## Установка и запуск

### Вариант 1. Готовая сборка

1. Скачать архив с релизом и распаковать его в любой каталог.
2. Запустить `FinUchet.exe`.
3. При первом запуске задать пароль — он будет запрашиваться при каждом входе.

Права администратора не требуются.

### Вариант 2. Сборка из исходного кода

```bash
# 1. Клонировать репозиторий
git clone https://github.com/n1k1tal0x/hub_docs_kt3.git
cd hub_docs_kt3

# 2. Восстановить зависимости
dotnet restore

# 3. Собрать решение
dotnet build -c Release

# 4. Выполнить тесты
dotnet test

# 5. Запустить приложение
dotnet run --project src/FinUchet.Wpf
```

### Подготовка дистрибутива

```bash
# Сборка, зависящая от установленной среды выполнения (компактная)
dotnet publish src/FinUchet.Wpf -c Release -r win-x64 --self-contained false -o publish/

# Самодостаточная сборка: .NET Runtime на компьютере пользователя не нужен
dotnet publish src/FinUchet.Wpf -c Release -r win-x64 --self-contained true ^
    -p:PublishSingleFile=true -o publish/
```

### Где хранятся данные

| Путь | Назначение |
|---|---|
| `%LOCALAPPDATA%\FinUchet\finuchet.db` | Файл базы данных SQLite |
| `%LOCALAPPDATA%\FinUchet\backups\` | Резервные копии, 5 последних |
| `%LOCALAPPDATA%\FinUchet\logs\` | Журналы работы, срок хранения 14 суток |
| `%LOCALAPPDATA%\FinUchet\settings.json` | Настройки интерфейса |

Каталог данных открывается из программы: **Настройки → О программе → «Открыть папку данных»**.

## Использование

### Первые шаги

1. **Задайте пароль** при первом запуске — он защищает доступ к финансовым данным.
2. **Создайте счета** в разделе «Счета»: кнопка «Добавить», укажите наименование, тип,
   валюту и начальный остаток.
3. **Проверьте категории** — справочник уже заполнен 24 предустановленными категориями,
   при необходимости добавьте свои и подкатегории.
4. **Регистрируйте операции** в разделе «Операции» кнопками «Доход», «Расход» и «Перевод».
   Остатки по счетам пересчитываются автоматически.
5. **Задайте месячные лимиты** в разделе «Бюджеты» — программа предупредит при достижении
   80 % и при превышении лимита.
6. **Формируйте отчёты** в разделе «Отчёты» за любой период.

### Часто используемые сочетания клавиш

| Сочетание | Действие | | Сочетание | Действие |
|---|---|:--:|---|---|
| `Ctrl+N` | Создать операцию | | `Ctrl+F` | Перейти к фильтру отбора |
| `Ctrl+I` | Операция «Доход» | | `F5` | Обновить данные раздела |
| `Ctrl+E` | Операция «Расход» | | `Ctrl+S` | Создать резервную копию |
| `Ctrl+T` | Операция «Перевод» | | `F1` | Открыть руководство пользователя |

### Обмен данными

Экспорт и импорт выполняются в разделе «Сервис». Формат файла — CSV, кодировка UTF-8,
разделитель `;`, структура по RFC 4180:

```csv
date;type;amount;account;account_to;category;subcategory;comment
2026-09-23;expense;2340.00;Карта «Мир» •4417;;Продукты;Супермаркеты;Магазин «Пятёрочка»
2026-09-21;income;96000.00;Карта «Мир» •4417;;Заработная плата;;Аванс за сентябрь
2026-09-19;transfer;10000.00;Наличные;Накопительный счёт;;;Пополнение накоплений
```

Строки, не прошедшие проверку, не импортируются — их номера и причины отклонения выводятся
в протоколе импорта. Полное описание формата — в
[приложении Б руководства пользователя](docs/user-guide/README.md#приложение-б-структура-файла-обмена-csv).
